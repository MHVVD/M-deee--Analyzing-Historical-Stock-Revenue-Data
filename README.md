# Tesla & GameStop: Stock Price vs Revenue

Final assignment for the IBM *Python Project for Data Science* course. The notebook
pulls historical share prices with `yfinance`, web-scrapes quarterly revenue tables
with `requests` + BeautifulSoup, cleans them with pandas, and plots price against
revenue for Tesla (TSLA) and GameStop (GME) in an interactive Plotly dashboard.

**Notebook:** [`tesla_gamestop_stock_revenue.ipynb`](tesla_gamestop_stock_revenue.ipynb)

**Tools:** Python · pandas · yfinance · BeautifulSoup · Plotly
